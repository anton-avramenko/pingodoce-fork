# Digital Card & Coupons PWA — POC

Mobile-first Progressive Web App proof of concept for UAT: a digital loyalty
card and coupons experience with live tab switching and dynamically generated,
scannable barcodes.

> **POC scope.** This is a demonstration build for UAT before full
> implementation. It uses an original placeholder logo/wordmark and demo data;
> official brand assets should be supplied by the brand team before any
> public-facing use.

## What it demonstrates

- **View A — Digital Card (Cartão):** brand header, user identifier and a
  large high-contrast barcode (SVG, crisp at any DPI) generated from a
  configurable card number.
- **View B — Coupons (Cupões):** list of active coupons; tapping one (e.g.
  the fuel coupon) opens a bottom-sheet detail with its own scannable
  barcode, discount value and expiration date.
- **Instant switching:** the fixed bottom navigation (Início / Cupões /
  Cartão / Mais) toggles views via client state — all views stay mounted, so
  switching Coupon → Card for scanning is instantaneous, with a subtle
  native-like fade/slide on the incoming view.
- **Hidden configuration:** open `/setup`, tap the header logo **5 times
  quickly**, or use *Mais → Configuração (POC)*. Configure the card number,
  holder name, barcode format and the coupon list (barcode, discount,
  expiration, type). Everything persists in `localStorage`, so the app loads
  instantly with the right data on later visits.
- **PWA:** web app manifest with `display: standalone` (hides the browser
  address bar when added to the home screen) plus a minimal service worker
  for instant/offline shell loading.
- **AI code scanning:** photograph or upload an image of a physical card, a
  coupon, a till receipt or plain text and let Claude read the code out of it.
  Available from *Cupões → Digitalizar* (creates a coupon) and from the camera
  buttons next to every code field in the setup screen (fills the field).
  Recognised codes are shown with a confidence badge and a barcode preview
  before you confirm; 13-digit codes with a valid checksum are saved as
  EAN-13, anything else as CODE128.

## Stack

- [Next.js 14](https://nextjs.org/) (App Router, `output: 'export'` — fully static)
- [Tailwind CSS 3](https://tailwindcss.com/)
- [JsBarcode](https://github.com/lindell/JsBarcode) (SVG rendering; CODE128, EAN-13, CODE39, ITF)
- [Anthropic TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript) (Claude vision + structured outputs for code scanning)
- Google AI Studio [Gemini API](https://ai.google.dev/) (REST, alternative provider for code scanning)
- TypeScript

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000 — use a mobile viewport (390×844)
```

## Production build (static)

```bash
npm run build      # generates icons + static site in ./out
npx serve out      # serve locally to test the PWA/service worker
```

## Deploying

The `out/` directory is a plain static site:

- **Vercel:** import the repo; framework preset *Next.js* (static export is detected).
- **Netlify:** build command `npm run build`, publish directory `out`.
- **GitHub Pages:** build with the sub-path base:
  `NEXT_PUBLIC_BASE_PATH=/<repo-name> npm run build`, publish `out/`.

Serve over **HTTPS** — service workers and home-screen install require it.

## Using it on a phone (UAT flow)

1. Open the deployed URL on the phone and **add to home screen** — the
   manifest's `display: standalone` removes the browser address bar.
2. Open `/setup` (or tap the header logo 5×) and enter the real card number
   and coupon barcodes, then **Guardar**.
3. In store: show the coupon detail (Cupões → coupon), then tap **Cartão**
   in the bottom bar — the card barcode is ready to scan instantly.

## AI code scanning

Recognition runs directly from the browser — the site is fully static, so
there is no backend to hold a secret. Two providers are supported and share
the same prompt, JSON schema and post-processing; pick one under
**Reconhecimento por IA → Serviço** in the setup screen:

| Provider | Model | Key | Sent to |
|---|---|---|---|
| Anthropic (Claude) | `claude-opus-5` (vision + structured outputs) | <https://platform.claude.com/> | `api.anthropic.com` |
| Google AI Studio (Gemini) | `gemini-2.5-flash` by default, editable | <https://aistudio.google.com/> → *Get API key* | `generativelanguage.googleapis.com` |

1. Create a **dedicated key with a spend limit** for UAT and revoke it
   afterwards.
2. Open the setup screen (*Listas → Configuração (POC)* or `/setup`), choose
   the provider, paste the key (and optionally a Gemini model name), then
   **Guardar**. Keys are stored in `localStorage` on that device only and are
   sent over HTTPS to the chosen provider and nowhere else.
3. Use *Cupões → Digitalizar* or a camera button in setup: **Tirar foto** opens
   the rear camera, **Carregar imagem** opens the gallery/file picker. Images
   are downscaled to ≤1568 px JPEG in the browser before upload.

There is deliberately no `NEXT_PUBLIC_*` key fallback: anything inlined at
build time would ship to every visitor of the public site. For a production
build, move the call behind a small proxy (serverless function / worker) that
holds the key and forwards the image.

What the model returns: every code it can read (digits under a barcode,
voucher numbers, alphanumeric promo codes) with a confidence level, plus the
coupon title, discount and expiry date when they are printed. Unreadable digits
are never guessed; the candidate is flagged *Leitura incerta* instead.

## Barcode notes

- Default symbology is **CODE128** (accepts any alphanumeric value).
- **EAN-13** requires 12 digits + valid check digit (13th digit); invalid
  values show an inline error instead of a broken barcode.
- Bars render as SVG at 2px module width and high contrast for reliable
  scanning from screens.
